# Blender 快捷键查询

一个纯 HTML 快捷键查询工具，**无需安装任何依赖**，手机和 PC 浏览器均可直接打开使用。

## 使用方式

直接打开 `index.html` 即可，或将文件传到手机浏览器中。

## 功能

- **187 条快捷键**，覆盖 12 个常用分类
- **实时搜索**：按快捷键名称、按键组合或功能描述快速筛选
- **分类筛选**：视图控制、选择操作、变换操作、编辑模式、雕刻、动画等
- **深色模式**：跟随系统主题自动切换
- **触控优化**：移动端单手操作适配
- **离线可用**：单文件，不依赖网络

## 快捷键分类

| 分类 | 说明 |
|------|------|
| 视图控制 | 视角切换、视图导航、显示设置 |
| 选择操作 | 框选、反选、选择相似等 |
| 变换操作 | 移动/旋转/缩放及轴约束 |
| 编辑模式 | 顶点/边/面编辑、循环切割、挤出等 |
| 修改器 | 细分表面、倒角、镜像 |
| 渲染 | 渲染图像/动画、渲染设置 |
| 动画 | 关键帧、播放控制、时间线导航 |
| 雕刻 | 笔刷控制、动态拓扑、蒙版 |
| 曲线 | 曲线编辑、控制柄类型 |
| 材质与纹理 | 节点连接器、纹理坐标 |
| 文件操作 | 新建、保存、导入导出等 |
| 工具 | 搜索、撤销、复制、吸附等 |
